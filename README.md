# 图像比例裁剪工具

直接双击 `index.html` 即可使用，无需安装依赖，也不会上传图片。

功能：

- 自动读取图像宽高，并匹配最接近的参考比例
- 支持 1:1、1:2、2:1、9:16、16:9、3:4、4:3、3:2、2:3、5:4、4:5、21:9、9:21
- 取满足目标比例的最大整数像素裁剪区域
- 默认仅裁剪，不缩放、不重采样
- 若上传图最长边超过 3000（大于 3000×3000），先按比例缩小，把最长边控制在 3000 以内，再按原逻辑裁剪
- 可拖动图片调整裁剪位置
- 支持导出 PNG、JPEG、WebP

说明：浏览器导出 JPEG / WebP 时会重新编码。若需要无损格式，请选择 PNG。
